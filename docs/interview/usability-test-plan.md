# 5 人可用性测试计划

## 目标

验证复杂研究任务中，用户是否理解执行计划、来源模式和降级提示，并能完成一次反馈。

## 受访者与方式

- 招募 3–5 名有 AI 工具使用经验的同学；不收集真实敏感资料。
- 每人 10–15 分钟，屏幕共享或线下操作；主持人只追问，不提示路径。
- 记录任务是否完成、关键耗时、观察到的犹豫点和原话；用受访者编号代替姓名。

## 任务脚本

1. 输入“比较两个 AI Agent 平台的公开能力，并给出适合求职准备的建议”。
2. 在执行前说明计划是否符合预期；如不符合，口述会怎样调整。
3. 判断当前来源是 live 还是 demo，并解释其对结论可信度的影响。
4. 找到来源链接，评价该报告是否足以支持进一步查证。
5. 提交“有帮助/无帮助”反馈，并说明原因。

## 复盘规则

- 完成率低于 80%：优先修复阻塞任务的界面或文案。
- 少于 80% 的受访者能识别 live/demo：增强来源状态的层级与解释。
- 少于 80% 的受访者能找到 URL：将来源链接置于结论下方并增加“打开原文”动作。
- 每轮只选一个最高频、最高影响问题进入下一版，记录假设、改动与复测结果。
